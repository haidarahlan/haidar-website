# Haidar Ahlan Ghaffar

### Developer

Welcome to my personal portfolio website repository! This is a modern, responsive, and high-performance portfolio website built using **Astro v7**, **Tailwind CSS v4**, and **Zero-JS** interactive components (like CSS-only lightbox modals and dark mode toggles).

---

## 🛠️ Tech Stack & Tools

- **Framework:** [Astro](https://astro.build/) (Static Site Generation)
- **Styling:** [Tailwind CSS v4](https://tailwindcss.com/) (CSS-first engine)
- **Architecture:** Zero-JS interactive components (via CSS `:target` and `:has()` checkbox hacks)
- **Core Skills:** Flutter, Dart, BLoC State Management, React, Frontend Web Development, Database Design & Programming

---

## 📂 Project Structure

This project follows a component-driven structure powered by Astro:

```text
haidar-website/
├── public/                # Static assets (images, logos, avatar)
├── src/
│   ├── components/        # Reusable dashboard/bento grid card components
│   │   ├── CertificatesCard.astro
│   │   ├── ContactCard.astro
│   │   ├── ExperienceCard.astro
│   │   ├── HeroCard.astro
│   │   ├── ProfileCard.astro
│   │   └── ProjectsCard.astro
│   ├── layouts/           # Page Layouts
│   │   └── Layout.astro
│   ├── styles/            # Global styles (Tailwind v4 imports and custom variants)
│   │   └── global.css
│   └── pages/             # App entry points
│       └── index.astro    # Bento grid dashboard homepage
├── package.json
└── astro.config.mjs       # Astro & Vite configuration
```

## 🧞 Commands

All commands are run from the root of the project:

| Command           | Action                                                |
| :---------------- | :---------------------------------------------------- |
| `npm install`     | Installs project dependencies                         |
| `npm run dev`     | Starts local dev server at `http://localhost:4321`    |
| `npm run build`   | Builds your production-ready static site to `./dist/` |
| `npm run preview` | Previews the build output locally                     |
